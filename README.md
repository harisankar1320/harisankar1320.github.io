# Harisankar Harikumar — Portfolio

Responsive geospatial-themed portfolio built with HTML, CSS and JavaScript.

## Preview locally
Run `python -m http.server 8000` from this folder, then open http://localhost:8000.

## Publish
Copy the contents of this folder into your cloned `harisankar1320.github.io` repository, review existing files, then run:
```powershell
git add .
git commit -m "Refresh geospatial portfolio"
git push origin main
```

## Before publishing
- Replace `https://www.linkedin.com/` in `js/main.js` with your real LinkedIn profile URL.
- Add your reference letter at `assets/documents/vlm-reference-letter.pdf`.
- Verify project links and descriptions. Some project cards link to your profile until exact repository URLs are confirmed.
- The GitHub repository list is fetched live from the public GitHub API and needs an internet connection.
